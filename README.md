# Feed MedBrain

Este repositório distribui boletins HTML e o manifesto de leitura.
O aplicativo não depende de prompts, credenciais ou código de geração públicos.

A geração e a validação editorial são mantidas no ambiente privado.
Novos arquivos exigem hash correspondente em `publication-allowlist.json`.
Essa lista protege contra alterações acidentais, não substitui o controle de acesso ao Git.

O método anterior foi retirado do HEAD em 13/09/2026. Commits históricos e
cópias externas podem conter versões antigas; esta mudança não reescreve o histórico.
